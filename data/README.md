# data/ — SYNTHETIC

Every file in this folder is generated. Fictional firm: Quillmere Advisory / Quillmere Service Center.

| File | Role |
|---|---|
| `query_catalog.csv` | 8 demo speech queries |
| `nexidia_style_metadata.csv` | One row per call (350 rows, 2026-03-18 only) |
| `transcripts_clob.csv` | Warehouse CLOB stand-in |
| `transcripts/*.txt` | Timestamped dialogue, one file per call |
| `time_baskets_5min.csv` | All-call counts in 5-minute baskets |
| `gold/burst_window.json` | Injected burst window for the demo check |

Do not treat IDs, names, or phrases as real clients or employees.
